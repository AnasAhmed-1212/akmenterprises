# AKM Enterprises website

The existing Next.js project now contains 11 distinct pages with shared navigation, contact details and footer:

- `/` — a concise homepage with the three-image hero and links to detailed pages.
- `/about` — company story, mission and commitments.
- `/products` — product catalogue and export process overview.
- `/products/sesame-seeds` — sesame specifications and applications.
- `/products/yellow-maize` — maize specifications and buyer categories.
- `/origin` — Pakistan sourcing, Karachi export gateway and seasonality.
- `/quality` — quality process, specification summaries and inspection coordination.
- `/global-reach` — international buyers and shipment planning.
- `/export-documentation` — packing, indicative loading and documentation support.
- `/faq` — nine questions grouped by product, shipment and ordering topics.
- `/contact` — email, phone, address, map search link and server-delivered inquiry form.

The six informational pages are statically generated by `app/[page]/page.tsx`, with individual content in `app/information-pages.tsx`. Unknown routes return 404. Each page has its own title and description. The main navigation and footer now link to routes rather than homepage sections.

Run the existing `npm run dev`, `npm run build` and `npm run lint` scripts as usual.

## Contact configuration

Company contact details are centralized in `app/site-data.ts`: contact@akmenterprises.info, +92 300 8375998, and Shop #1, Nargis Tower, Gulistan-e-Johar, Block #10, next to Hascol Petrol Pump, Karachi. The header shows a clickable phone number and email; the inquiry section and footer include the full address.

The inquiry form validates buyer details and sends approved requests through `app/api/inquiry/route.ts` using Nodemailer. To enable delivery, create an uncommitted `.env.local` file with `SMTP_PASSWORD=` followed by the mailbox password, then restart the local server. On the production host, set the same `SMTP_PASSWORD` environment variable and redeploy. The configured mail service is GoDaddy Professional Email powered by Titan: `smtpout.secureserver.net`, port `465`, SSL, with `contact@akmenterprises.info` as the authenticated mailbox. `INQUIRY_TO_EMAIL` is optional and routes form submissions to a separate monitored mailbox; without it, the contact mailbox receives them. The endpoint logs Titan's message ID and response after a recipient is accepted. Never commit or share the mailbox password.

## Content and visuals

- Main business copy and specifications come from AKM_Enterprises_Complete_Website_Content.docx.
- Product data and image URLs live in `app/site-data.ts`.
- Online photos use Unsplash and Wikimedia Commons, with source and license credits in the footer. Photographs are representative, not claims about AKM facilities or shipments.
- Five additional online images cover a cornfield, harvested maize, inspection, shipping containers and a cargo vessel. Dedicated pages use image banners, photo galleries and supporting editorial imagery.
- The AKM wordmark uses text and a Lucide Sprout icon until an official logo is supplied.
- Motion respects the browser's reduced-motion preference. FAQ sections use native accessible disclosure elements.
- The hero crossfades between the field, sesame and maize photographs every six seconds with a 1.5-second transition. Image selection and pause/play controls are provided. Autoplay skips unloaded slides, pauses in hidden tabs, and is disabled for reduced-motion preferences.
- No unsubstantiated certifications, testimonials, export destinations, or company statistics were added.

## Hosting

The existing Next.js architecture is preserved. This project builds with Next.js; it does not yet produce the Cloudflare Worker build required by Sites hosting. It is ready for a compatible Next.js host, or a separate Cloudflare adapter setup when hosting is chosen.
